# Credit Score Prediction

This project predicts credit scores (Low, Average, High) using machine learning models.

## 🔧 Tools Used
- Python
- Pandas, NumPy
- scikit-learn
- Jupyter Notebook

## 🧠 Features
- Data cleaning and preprocessing
- Label Encoding & Standardization
- Model training (Random Forest Classifier)
- Evaluation using Accuracy, Confusion Matrix & Classification Report

## 📈 Accuracy
Achieved 100% accuracy on the test set.

## 💾 Dataset
Used from Kaggle: [Credit Score Dataset](https://www.kaggle.com/...)
